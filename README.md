### 🚗 Vietnamese License Plate Recognition

Real-time Vietnamese License Plate Recognition pipeline for camera / RTSP streams.

```text
Camera / RTSP
      ↓
YOLO Plate Detection
      ↓
Plate Crop
      ↓
PaddleOCR
      ↓
Validation
      ↓
Majority Vote
      ↓
Deduplication
      ↓
HTTP Event
```

🔗 [View Repository](https://github.com/hatanphong44/vn-license-plat)
